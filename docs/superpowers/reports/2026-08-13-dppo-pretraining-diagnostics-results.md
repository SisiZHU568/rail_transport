# DPPO 预训练有效性双指标诊断结果

## 1. 诊断范围

本次诊断使用中等规模 `dppo-expert-v2` 数据集的验证集和测试集，共 23 条未参与预训练参数更新的专家记录：

- 验证集：12 条；
- 测试集：11 条；
- 成本教师：15 条；
- 可靠性教师：8 条；
- 均衡教师：0 条。

诊断在 RTX 5060 GPU 上比较结构完全相同的随机初始化模型和 20 epoch 预训练模型。每条记录对两个模型使用同一个扩散采样种子，场景按 Episode seed 和慢步重放，并使用执行前资源与故障快照检查原始可行性。

本次只读取数据和检查点，没有修改模型参数，也没有运行新的在线 PPO 训练。

## 2. 连续动作拟合

| 指标 | 随机模型 | 预训练模型 | 变化 |
|---|---:|---:|---:|
| 平均动作 MSE | 1.463603 | 1.424090 | -2.70% |
| 中位动作 MSE | 1.524074 | 1.524074 | 基本不变 |
| 平均动作 MAE | 0.981662 | 0.961321 | -2.07% |
| 中位动作 MAE | 1.000741 | 1.011111 | 略变差 |

23 条记录中只有 8 条的预训练 MSE 低于随机模型，改善比例为 34.78%。设计门槛要求平均 MSE 至少下降 10%，并且超过一半记录得到改善；当前两项都未达到。

因此不能认为当前预训练模型已经学到了稳定的连续专家信号。

## 3. 解码部署语义

| 指标 | 随机模型 | 预训练模型 | 变化 |
|---|---:|---:|---:|
| 副本数准确率 | 55.07% | 55.07% | 0 |
| 节点前缀顺序命中率 | 8.70% | 8.70% | 0 |
| 节点前缀集合命中率 | 11.59% | 10.14% | -1.45 个百分点 |
| 主副本保留时间 MAE | 10.6087 秒 | 9.8381 秒 | -0.7706 秒 |
| 备副本保留时间 MAE | 8.6609 秒 | 8.6609 秒 | 0 |

只有主副本保留时间误差略有下降；副本数、节点顺序和节点集合均没有改善。两个模型的副本数输出分布也完全一致：

- 2 副本：30 个 VNF；
- 3 副本：39 个 VNF。

这表明当前预训练尚未改变最重要的离散部署语义。

## 4. 原始可行性与投影

| 指标 | 随机模型 | 预训练模型 | 变化 |
|---|---:|---:|---:|
| 原始动作可行率 | 17.39% | 17.39% | 0 |
| 投影成功率 | 100% | 100% | 0 |
| 平均投影修改比例 | 23.45% | 22.90% | -0.54 个百分点 |

预训练没有提高原始动作可行率。投影修改比例只下降约 0.54 个百分点，且连续拟合门槛未通过，因此不能把这点微小变化解释为策略已经学会约束。

## 5. 方向性结论

诊断结论为：

> `continuous_signal_not_learned`：当前预训练模型尚未学到稳定的连续专家信号，因此也不能期待它稳定改善离散部署语义或原始可行性。

这与上一轮训练现象一致：中等规模数据包含 57 条训练标签，而 batch size 为 64，每个 epoch 只有一次优化器更新；20 epoch 实际只有约 20 次预训练更新。在线 PPO 阶段有 200 次更新，预训练初始化很快被在线更新主导。

此外，当前未见记录只包含成本教师和可靠性教师，没有均衡教师，诊断不能评价模型对均衡教师方案的拟合能力。

## 6. 下一步单一决策

下一步不运行新的在线训练，也不修改奖励函数、投影器或 CLARABEL。只修改预训练过程，使配置明确控制“实际优化器更新次数”，然后在同一数据集上完成约 200 次预训练更新，并再次运行完全相同的双指标诊断。

判断顺序应保持为：

1. 先达到连续信号门槛：平均 MSE 至少下降 10%，且超过一半未见记录改善；
2. 再观察副本准确率、节点前缀和原始可行率是否改善；
3. 只有预训练诊断通过后，才重新进行稳定性校准和 20×2 在线训练。

这样能够把“预训练没有充分更新”和“动作参数化不能表达部署语义”两个问题分开，避免继续用在线奖励曲线间接猜测。
