# DPPO 论文对齐稳定训练与校准设计

**日期：** 2026-08-11
**适用分支：** `codex/dppo-main-algorithm`
**设计状态：** 已完成讨论，等待书面 review
**依据：** *Diffusion Policy Policy Optimization*（arXiv:2409.00588v1）

## 1. 背景与问题证据

现有 DPPO 主链已经能够完成专家数据生成、扩散预训练、在线 PPO 更新、检查点恢复和独立评估，但 Task 16 的最小冒烟训练出现了以下稳定性信号：

- `gradient_norm = 4080.8565`；
- `approximate_kl = 484129.8562`；
- `clip_fraction = 0.9`。

这些值仍为有限数，因此流程没有崩溃，但它们明显不适合直接扩展到 200 次正式训练迭代。根因检查发现，当前余弦扩散调度在最后一个去噪步骤使用 `0.001` 的反向标准差，并将同一个标准差同时用于动作采样和 PPO 高斯概率计算。当前 5 个可训练去噪步骤对应的标准差约为：

```text
t=4: 0.19515
t=3: 0.16168
t=2: 0.12324
t=1: 0.07583
t=0: 0.00100
```

DPPO 论文建议区分探索噪声和概率计算噪声，并在概率计算时将标准差下限提高到 `0.1`，以避免对数概率出现过大幅值。论文还采用 KL 阈值早停，并以 10%–20% 的裁剪比例作为选择 PPO 裁剪系数的经验目标。

## 2. 目标与非目标

### 2.1 目标

1. 将当前在线训练稳定机制与 DPPO 论文的关键实践对齐。
2. 分离训练采样、概率计算和独立评估使用的标准差下限。
3. 在正式训练前，用固定种子公平校准 `clip_ratio`。
4. 让正式训练只能使用通过校准且与当前配置、预训练检查点匹配的稳定性文件。
5. 保持全部参数由配置或校准产物提供，不在 Python 代码中写死实验规模。
6. 在训练历史和检查点中保存完整稳定性元数据，支持论文复现。

### 2.2 非目标

- 不修改奖励函数及其权重。
- 不改变慢尺度状态空间和联合动作语义。
- 不改变约束投影、约束审计或快尺度修复算法。
- 不加入自动学习率调节、自动回滚或训练期间自动选择裁剪系数。
- 本阶段不加入逐去噪步骤的不同裁剪系数；只有统一裁剪系数无法达标时才重新设计该扩展。
- 不启动正式长训练，也不把校准短跑结果作为论文性能结果。

## 3. 与双时间尺度 SFC 工程的适用关系

DPPO 继续只负责慢尺度联合决策。其原始连续动作包含：

- 每个 VNF 的候选计算节点排序分数；
- 每个 VNF 的两副本/三副本连续判定量；
- 每个 VNF 的主副本和备副本保留时间。

连续动作经过约束投影后形成离散、可执行的 VNF 部署意图。投影器、约束审计和快尺度修复被视为环境的一部分，PPO 不需要对这些模块求导，而是根据最终执行结果的奖励更新策略。快尺度仍使用确定性修复和优化，不引入 DPPO。

因此，本设计只改变扩散采样概率和 PPO 更新稳定性，不改变论文中的双时间尺度职责边界。

## 4. 方案比较与选择

### 4.1 方案 A：论文对齐校准（采用）

分离三类标准差，加入 KL 早停和优势归一化，并从 `{0.1, 0.01, 0.001}` 中选择满足目标裁剪比例的最大值。优点是论文依据清晰、参数数量少、结果易复现；缺点是正式训练前需要一次短校准。

### 4.2 方案 B：只提高概率标准差（不采用）

只将概率标准差下限改为 `0.1`。改动最少，但无法阻止多轮 PPO 更新再次偏离旧策略，也不能系统选择适合 27 维联合动作的裁剪系数。

### 4.3 方案 C：工程自适应保护（不采用）

增加自动降低学习率、自动回滚或动态裁剪。保护更强，但会增加难以在论文中定义和复现的控制逻辑，也会扩大调参空间。

## 5. 稳定训练参数

配置增加以下明确参数：

```yaml
dppo:
  diffusion:
    training_sampling_min_std: 0.01
    probability_min_std: 0.10
    evaluation_sampling_min_std: 0.001

  training:
    target_kl: 1.0
    normalize_advantages: true

  stability_calibration:
    clip_ratio_candidates:
      - 0.1
      - 0.01
      - 0.001
    target_clip_fraction_min: 0.10
    target_clip_fraction_max: 0.20
    iterations_per_candidate: 3
    episodes_per_iteration: 2
    seed_start: 14000
```

这些值具有以下含义：

- `training_sampling_min_std` 控制在线训练探索；
- `probability_min_std` 只控制 PPO 新旧策略概率计算；
- `evaluation_sampling_min_std` 降低独立评估的随机扰动；
- `target_kl` 控制一次 rollout 上允许的策略变化；
- 裁剪候选及目标区间只用于正式训练前校准。

正式实验可以通过 YAML 扩大校准 Episode 数，但不需要修改 Python 源码。

## 6. 标准差数据流

余弦调度继续计算理论反向均值和理论反向方差。使用方根据目的应用不同下限：

```text
理论反向标准差
    ├── 在线动作采样：max(理论值, 0.01)
    ├── 旧/新策略概率：max(理论值, 0.10)
    └── 独立评估采样：max(理论值, 0.001)
```

在线采样时，下一步去噪动作根据训练采样标准差生成；同一个实际样本的旧策略对数概率使用概率标准差重新计算并保存。PPO 更新阶段的新策略对数概率也使用完全相同的概率标准差。由此保证新旧概率可比较，同时避免最后去噪步骤的对数概率被 `0.001` 放大。

## 7. 优势计算顺序

优势归一化放在环境时间尺度 GAE 之后、去噪步骤折扣之前：

```text
原始奖励与旧价值
    ↓
按环境时间尺度计算 GAE 和价值回报目标
    ↓
在完整 rollout 上一次性归一化 GAE 优势
    ↓
乘以各去噪步骤的 gamma_DENOISE 权重
    ↓
计算 PPO 裁剪代理目标
```

数学形式为：

```text
A_norm(t) = (A(t) - mean(A)) / (std(A) + epsilon)
A(t, k) = gamma_DENOISE^k * A_norm(t)
```

实现约束：

- 不归一化原始奖励；
- 不归一化价值网络的回报目标；
- 不在每个小批次中重新计算均值和标准差；
- 不在应用去噪折扣后再次归一化；
- rollout 少于 2 个样本或标准差低于数值阈值时保留原始优势，避免单样本信号被归零或产生非有限值。

这项处理不引入新的实验超参数，也不改变奖励各组成项的含义。

## 8. KL 计算与提前停止

对每个待更新小批次，先使用当前策略重新计算对数概率：

```text
log_ratio = new_log_probability - old_log_probability
ratio = exp(log_ratio)
approximate_kl = mean((ratio - 1) - log_ratio)
```

更新顺序如下：

1. 计算当前小批次的新概率、概率比、裁剪比例和近似 KL；
2. 如果近似 KL 已达到 `target_kl`，则不执行当前及剩余小批次的策略和价值更新；
3. 否则执行裁剪 PPO 更新和价值网络更新；
4. 记录已完成的优化器步数、最大/平均 KL、平均裁剪比例和是否触发早停。

KL 早停是正常稳定性事件，不视为程序异常。非有限概率、损失或梯度仍抛出异常，并阻止保存被污染的检查点。

## 9. 裁剪系数校准

新增独立校准入口，按配置顺序测试 `{0.1, 0.01, 0.001}`。每个候选必须：

1. 从同一个预训练检查点重新创建全新的智能体；
2. 使用完全相同的 Episode 种子、迭代数和每轮 Episode 数；
3. 不继承前一个候选的模型、优化器或随机数状态；
4. 记录每轮奖励、策略损失、价值损失、梯度范数、平均/最大 KL、裁剪比例和实际更新步数。

候选合格条件：

- 所有数值均有限；
- 最大近似 KL 小于 `target_kl`；
- 平均裁剪比例位于 `[0.10, 0.20]`；
- 至少完成一次策略更新。

在所有合格候选中选择数值最大的 `clip_ratio`。校准只依据训练稳定性，不依据独立测试集的最终性能，避免测试信息泄漏。如果没有候选合格，仍输出完整诊断报告，但 `qualified=false` 且不选择裁剪系数。

## 10. 稳定性文件

校准输出 UTF-8 JSON `stability_profile.json` 和候选明细 CSV。JSON 至少包含：

```text
schema_version
qualified
selected_clip_ratio
config_hash
pretrained_checkpoint_sha256
candidate_values
target_clip_fraction_range
target_kl
episode_seeds
iterations_per_candidate
episodes_per_iteration
candidate_metrics
failure_reasons
```

正式在线训练必须显式传入该文件。训练开始前验证：

- `qualified` 必须为真；
- 配置哈希必须与当前配置一致；
- 预训练检查点 SHA-256 必须一致；
- 选择值必须属于配置中的候选集合；
- 标准差、KL 和裁剪区间必须与当前配置一致。

任一检查失败都拒绝启动正式训练。在线检查点和训练历史保存稳定性 profile 摘要及其 SHA-256，独立评估报告也输出该摘要。

## 11. 代码边界

### `src/dppo_diffusion.py`

- 保留理论余弦调度计算；
- 提供带显式下限的反向标准差接口；
- 使用中文注释解释探索标准差与概率标准差的区别。

### `src/dppo.py`

- 使用训练采样标准差生成去噪轨迹；
- 使用概率标准差保存和重算对数概率；
- 在 GAE 后归一化外层优势；
- 在优化器更新前执行 KL 检查；
- 输出更完整的稳定性指标。

### `src/dppo_stability.py`

- 定义不可变的稳定性 profile 和候选结果；
- 负责合格判定、选择、保存、加载及兼容性验证；
- 不负责环境执行或神经网络更新。

### `run_dppo_stability_calibration.py`

- 加载同一预训练检查点并公平运行所有候选；
- 要求显式 `--output-root`；
- 输出 profile、CSV 和简洁控制台摘要。

### `run_dppo_training.py`

- 正式 CLI 要求 `--stability-profile`；
- 使用 profile 中的裁剪系数创建在线智能体；
- 在历史和在线检查点中持久化稳定性信息。

### `run_dppo_evaluation.py`

- 使用评估采样标准差；
- 验证并报告在线检查点携带的稳定性信息。

### `configs/debug.yaml`

- 保存三种标准差、KL 阈值和校准规模；
- 不保存自动调节规则。

## 12. 错误处理

- 非有限标准差、概率、损失、优势、回报或梯度：抛出明确异常。
- 校准候选没有产生转移或优化器步：该候选不合格并记录原因。
- 所有候选均不合格：生成诊断文件，正式训练拒绝继续。
- profile 缺字段、模式版本错误、哈希不匹配或候选值非法：加载失败并指出具体字段。
- KL 早停：保留已经完成的安全更新，记录状态，正常结束当前 PPO 更新。
- 异常更新不清空 rollout buffer，便于复现；成功或正常 KL 早停后清空 buffer。

## 13. 测试策略

实现遵循测试驱动顺序，至少覆盖：

1. 三种用途使用各自的标准差下限；
2. 相同种子和配置产生相同采样轨迹；
3. 策略更新前，新旧概率在概率下限下基本相等；
4. 优势只在完整 rollout 上归一化，并位于 GAE 与去噪折扣之间；
5. 单样本和零方差优势不产生 `NaN`；
6. KL 达到阈值后不执行当前及剩余优化器步骤；
7. KL 早停、实际更新步数和最大 KL 正确进入指标；
8. 每个裁剪候选从同一检查点和随机状态开始；
9. 相同种子重复校准得到相同候选明细和选择结果；
10. 选择满足条件的最大候选；
11. 无候选合格时生成不合格报告并阻止正式训练；
12. profile 与配置或检查点不匹配时拒绝加载；
13. 在线检查点恢复后稳定性元数据保持一致；
14. 评估使用 `evaluation_sampling_min_std` 且不更新模型；
15. 全量测试和临时“数据集→预训练→校准→在线训练→恢复→评估”链通过。

## 14. 验收标准

- 校准选择的平均裁剪比例位于 10%–20%；
- 校准期间最大近似 KL 小于 1；
- 所有报告的奖励、损失、梯度和概率指标为有限值；
- 正式训练没有合格 profile 时不能启动；
- profile 与在线检查点可追溯到准确配置和预训练检查点；
- 活动代码不重新引入已停用算法；
- 不修改正式论文结果目录；
- 新增代码包含面向初学者的必要中文注释；
- 全量测试零失败。

## 15. 兼容性与实验迁移

Task 16 之前生成的检查点没有稳定性 profile，只可用于历史流程验证，不作为正式论文检查点。稳定机制实现后，应按新配置重新生成正式专家数据、预训练检查点和在线训练检查点。由于目前尚未开始正式长训练，不需要迁移或覆盖任何正式模型。

校准种子、正式训练种子和独立评估种子必须使用互不重叠的范围。校准产生的短跑指标只用于选择稳定超参数，不进入最终算法性能表。
