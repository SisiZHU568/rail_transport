# DPPO 可行专家标签设计

## 1. 问题与目标

当前 GPU 冒烟数据共有 8 条教师记录，其中所有教师原始动作的 `raw_feasible` 都是 `False`。现有收集器虽然只让最终执行可行的记录进入行为克隆分区，却仍把投影前的 `proposal.relaxed_action` 保存为 `expert_action`。因此，扩散模型实际模仿的是需要投影器纠正的节点排名。

本次修改的目标是：行为克隆数据只保存经过现有硬约束投影后、重新编码得到的可行连续动作。奖励函数、DPPO 在线 PPO 更新、动作维度以及 CLARABEL 快层求解均保持不变。

## 2. 数据流

每个慢时间尺度样本按以下顺序生成：

```text
当前因果状态
  → 仿真教师生成原始连续建议
  → 在线环境按原逻辑执行原始建议
  → 投影器生成可行 FunctionDeploymentIntent
  → 将投影后的节点前缀重新扩展为完整节点排名
  → 使用 DPPOActionSpace 重新编码连续专家标签
  → 再次解码并用同一投影输入验证标签原始可行
  → 最终执行无违约时进入行为克隆数据，否则进入诊断数据
```

教师原始建议仍用于真实仿真执行，保证成本、路由、冷启动和违约指标与现有在线闭环一致。只修改写入预训练集的监督标签。

## 3. 投影后动作的重新编码

投影成功后，每个 `FunctionDeploymentIntent` 只包含实际选择的副本节点。重新构造完整排名时采用稳定规则：

1. 投影选中的 `preferred_node_ids` 保持现有主副本顺序，放在排名最前；
2. 未选节点按照教师原始完整排名依次补在后面；
3. 副本数保持投影意图中的 `replica_count`；
4. 主、备容器保留时间保持投影意图中的数值；
5. 重新编码后必须再解码一次，确保连续向量和离散含义一致。

该规则只改变违反硬约束的节点前缀，不对其余节点进行额外优化，也不把投影器升级为新的部署算法。

## 4. 数据模式

数据集模式升级为 `dppo-expert-v2`。每条记录明确区分：

- `teacher_proposal_raw_feasible`：教师最初建议是否无需投影即可执行；
- `expert_action_feasible`：最终写入 `expert_action` 的标签是否原始可行；
- `projection_change_ratio`：教师原建议被投影器修改的节点分配比例；
- `final_feasible`：投影和快层执行后是否没有违约。

行为克隆分区的准入条件同时要求：

- `expert_action_feasible=True`；
- `final_feasible=True`。

任何不满足条件的记录都进入 `diagnostics.npz`，并保留拒绝原因。旧的 v1 数据集因模式版本不匹配不能被新预训练流程静默复用。

## 5. 失败处理

- 投影失败：没有可行意图，不构造伪标签；保留教师原始动作作为诊断载荷，设置 `expert_action_feasible=False`。
- 标签重新编码后仍不可行：视为实现或场景一致性错误，记录进入诊断并给出明确原因，不能进入行为克隆分区。
- 最终执行违反 SLA 或硬约束：即使标签本身可行，也只进入诊断分区。
- 不添加投影修改惩罚，不改变在线奖励数值。

## 6. 修改范围

主要修改：

- `src/dppo_dataset.py`：构造投影后专家标签、升级字段和准入规则；
- `tests/test_dppo_dataset.py`：覆盖投影后标签、模式往返、诊断过滤和旧字段拒绝；
- `run_dppo_dataset_generation.py`：若输出摘要依赖旧字段名称，仅做相应显示更新。

不修改：

- `src/rl_reward.py`；
- `src/dppo.py`；
- `src/dppo_projection.py` 的在线投影算法；
- `src/fast_convex_scheduler.py`；
- 在线动作维度和概率计算。

## 7. 核心验证

代码修改完成后只运行相关核心测试，并生成一个小型验证数据集。验收条件是：

1. 数据集模式为 `dppo-expert-v2`；
2. 所有行为克隆分区中的 `expert_action_feasible` 均为 `True`；
3. 加载后重新解码并结合对应因果状态检查时，行为克隆标签原始可行率为 100%；
4. 教师原建议仍可记录为不可行，证明诊断信息没有被掩盖；
5. 奖励函数相关文件无差异；
6. 旧 v1 数据集不会被当作新数据继续预训练；
7. 通过后再重新生成数据、GPU 预训练、稳定性校准和 `20 × 2` 在线训练，对比原始动作可行率与投影修改比例。
